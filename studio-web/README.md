# MeKaBu モジュール設定

左右の XIAO nRF52840 にそれぞれ MKB-ZeroShift-left.uf2 と MKB-ZeroShift-right.uf2 を書き込みます。左右の拡張ソケットには、それぞれ独立した設定を保存できます。初期設定は「未装着」です。

1. 左側を USB で PC に接続するか、Bluetooth でペアリングします。
2. デスクトップ版 Chrome または Edge で設定ページを開き、「USB 接続」または「Bluetooth 接続」を選びます。USB の場合は左側の Studio 用シリアルポート、Bluetooth の場合は MeKaBu を選びます。
3. 「設定する側」で左右を選び、拡張モジュールを選んで「設定を保存」を押します。右側を設定するときは、左右の電源を入れて左右間の接続を確立してください。
4. 設定した側の電源を切り、モジュールを取り付けて起動します。左を再起動した場合は再接続し、右を再起動した場合は「右側」で「再読込」を押します。「起動中のモジュール」で適用結果を確認できます。

選択肢は未装着、PMW3610 トラックボール（右側は v4 配線）、アナログスティック、エンコーダ、1u キー、RZT、トラックパッド、LPPS（ADS1220）です。モジュールの種類と左右の配線は MeKaBu の設定側で定義しています。各側は起動時に自身の保存値を読み、選択された入力ドライバーを初期化します。LPPS とピンを共用するため、統合版のキーマトリックスは全モードで 10 ms ポーリングです。

## Web UI のビルド

このディレクトリで以下を実行し、表示された localhost の URL を開きます。

```sh
npm ci
npm run build
python3 -m http.server 8768 --bind 127.0.0.1 --directory dist
```
